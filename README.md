# Nexumpedia

**Conhecimento em conexão.**

A Nexumpedia é uma enciclopédia digital com identidade própria e interface inspirada no padrão clássico de enciclopédias wiki. Diferentemente de uma wiki aberta, a proposta editorial é que artigos sejam criados e revisados por **administradores e colaboradores autorizados**.

## Estado atual

Este primeiro marco define a identidade visual e a experiência-base do produto:

- página inicial;
- página de artigo;
- interface inicial do painel editorial;
- layout responsivo;
- modo claro/escuro;
- marca própria da Nexumpedia;
- componentes visuais reutilizáveis.

O painel incluído nesta etapa é apenas um protótipo de interface. Autenticação, permissões, banco de dados, upload real de imagens, histórico e publicação serão implementados na etapa de backend.

## Estrutura

- `index.html` — página principal
- `artigo.html` — demonstração de um artigo
- `painel.html` — protótipo do painel editorial
- `assets/css/nexumpedia.css` — identidade visual e responsividade
- `assets/js/nexumpedia.js` — interações básicas
- `assets/img/nexumpedia-mark.svg` — símbolo próprio da Nexumpedia

## Princípios do projeto

1. Interface familiar para leitura de artigos longos.
2. Identidade visual própria — sem usar nome, logo ou ativos da Wikipedia.
3. Conteúdo editorial controlado por usuários autorizados.
4. Referências e histórico de revisão como parte central da confiabilidade.
5. Acessibilidade, responsividade e leitura confortável.

## Próxima etapa

A próxima fase transformará este protótipo estático em uma aplicação real, com autenticação, funções de administrador e colaborador, criação e edição de artigos, rascunho/revisão/publicação, biblioteca de imagens, histórico de versões, referências, categorias, busca e banco de dados.
